## À propos

Je conçois des applications web et des outils numériques, de l'idée à la mise en production. J'aime partir d'un besoin concret, choisir les bons outils et construire une solution simple à utiliser et à faire évoluer.

## Ce que je construis

| Projet | Description |
| --- | --- |
| **[MChaix Studio](https://mchaix.fr/)** | Développement et accompagnement de projets numériques sur mesure pour les professionnels et les organisations. |
| **[Rotaract Toul-Commercy](https://mchaix.fr/realisations/rotaract-toul-commercy)** | Plateforme web présentant le club, ses actions et ses événements, tout en facilitant son administration. |
